# 科研任务分类规则

## 五个阶段的边界

| 主分类 | 主要任务 | 当前条目示例 |
| --- | --- | --- |
| Search | 查找已有论文、数据、结构、序列、注释与指南 | ClinVar、GTEx、PubMed、蛋白结构检索 |
| Read | 读取、提取、理解和整理文档内容 | Docling、PDF、文献精读 |
| Reason | 研究设计、证据评议、机制解释和方案判断 | 同行评审、系统综述、临床变异解释 |
| Experiment | 数据处理、统计计算、组学分析、实验流程与科研绘图 | RNA-seq、定性主题分析、时间序列、Excel 公式 |
| Write | 撰写、编辑、引用管理、发表和学术传播 | Word、PPT、Zotero、研究成果归档 |

按主要交付物分类。例如数据库查询以 Search 为主；对用户数据进行比对、计算和统计以 Experiment 为主；系统综述以跨研究证据综合为核心，归入 Reason；定量合并效应量的 meta-analysis 归入 Experiment。通用文档工具的分类表示它在科研流程中的可用角色，不代表它专用于医学。临床相关条目的分类仅说明用途，不验证其疗效或临床可靠性。

## 当前条目与新条目

- `classification_catalog.yaml` 基于 2026-09-15 已采集的 415 条名称、介绍核对，按相同任务分组。
- 映射绑定仓库、完整相对路径及“名称 + 换行 + 原始介绍”的 SHA256 前 20 位。其他仓库同名条目不会复用；介绍变化时回退关键词并标记待复核。
- 既有精确规则继续提供 11 条中文简介与 3 条已有范围外标记。内容指纹变化时不会套用旧精确规则。
- 新条目依靠关键词规则：名称权重 8，首句 4，其他正向介绍 1；同一分类的同义词不叠加得分。只将名称或首句中明确命中的其他任务作为辅助分类。同分时保留确定性排序并提示复核。
- 删除常见“Do not use / Not for”等否定用途片段，避免负面示例带来正向命中。此规则是有限文本启发式，不理解所有自然语言否定。
- 领域与阶段独立：例如医学数据库是“Search + 生物医学”；时间序列分析可以是“Experiment + 公共卫生”。
- 安装、开发、部署工具标记“科研基础设施”；职业、实验室团队事务、通用创作等标记“通用或科研事务辅助”。它们保留在未分类筛选中并可通过中文标签搜索，不额外隐藏。
- 原始元数据不完整的 3 条继续保留警告和待复核状态；补充任务分类不会把解析失败改成成功。

## 更新与个人数据

规则、核对目录及算法版本共同产生分类版本。启动应用时，在持有单实例锁且同步任务尚未启动的情况下重新分类已保存条目，升级前自动创建 SQLite 备份。只写 `auto_json`、`rule_version`、必要时的 `changed_at`，不改变来源配置、采集状态、文件 SHA、收藏、精选、备注、证据和人工覆盖。没有版本变化时不重复写库或创建备份。

修改规则后执行 `uv sync` 并重启。解析器版本不一致的旧条目保持可重抓取状态，等待下一次来源刷新。添加核对映射时应阅读当前名称和介绍，提供用途依据，并更新内容指纹；不得将上游 Skill 正文当作要执行的指令。

## 本次本地数据结果

默认可见 412 条，按主分类计数：Search 64、Read 7、Reason 61、Experiment 189、Write 25，辅助/未分类 66。另有 3 条已有范围外条目；没有新增范围外或删除条目。未分类由 344 降至 66。

页面分类筛选只匹配主分类；卡片继续显示其他阶段的辅助能力，并加上“辅助：”标识。

上述数量基于本次数据快照；新增来源、上游变动或用户覆盖后可能变化。测试含 37 个真实介绍分类样例、新来源关键词判别、否定用途、内容变化、同名隔离及离线升级的数据保护。
